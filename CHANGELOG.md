# Changelog

All notable changes to CC:HQ Speakers Sable Compatibility are documented in
this file.

## [0.4.0] - 2026-10-23

### Added

- Added compatibility with CC:HQ Speakers 1.1.0 and newer for NeoForge 1.21.1.

## [0.3.0] - 2026-10-19

### Added

- Added compatibility with CC:HQ Speakers 1.0.9 for NeoForge 1.21.1.

## [0.2.0] - 2026-10-12

### Added

- Added compatibility with CC:HQ Speakers 1.0.7 and 1.0.8 for NeoForge 1.21.1.

## [0.1.1] - 2026-10-09

### Fixed

- Restored compatibility with CC:HQ Speakers 1.0.4 while retaining support
  for the earlier 1.1.4 NeoForge build.
- Preserved speaker volume support up to 16 with updated CC:HQ Speakers.

## [0.1.0] - 2026-09-16

### Added

- Initial release with Sable-aware positioning for CC:HQ Speakers audio.
- Audio now reaches players around a speaker placed in a moving Sable
  sublevel, and continues to follow the sublevel while it moves.
- Extended speaker volume support up to 16, with a matching audible range of
  up to 256 blocks.
